# Custom Quiet Home

This is AnthonMS's Q60C adaptation of [quiet-tizen](https://github.com/jss8649/quiet-tizen), based on commit `cf518d7a9278dca7990e27756218258e44044a29`.

Start with the repository [README](../README.md), [manual](../docs/MANUAL.md) and [recovery guide](../docs/RECOVERY.md). The older U8000F documentation remains in this directory as upstream reference, not a Q60C installation recipe.

Current source includes the native dock launcher, settings, YouTube device-code recommendations, Jellyfin Quick Connect media rows, global shortcuts, Moonfin guide/channel bridge and an optional headless boot-privacy helper.

Preserve `NOTICE.md`, `LICENSE`, `licenses/` and boot-helper attribution. Samsung binaries, account data, certificates and publisher artwork are not distributed.
