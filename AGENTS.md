# Working in this repository

Read README.md and docs/MANUAL.md before TV operations. The current Q60C source is under quiet-tizen; its AGENTS.md also applies there. Preserve the repurposed Bixby Promotion and Gaming Hub Service slots. Never apply the older U8000F profile to the Q60C.

Private data belongs in ignored .local folders. Never publish tokens, private configurations, proprietary binaries, account data or raw backups. The public guides use placeholders. Keep all license notices.

Use only the explicitly identified TV. Root/SDB sessions are sequential. Back up the current device and prepare targeted inverses before mutation. Wait for root cleanup before reboot or standby. Do not flash firmware, alter the global passwd/SDB key, disable core security, delete packages indiscriminately or replace live databases wholesale.

On the owner's configured TV, Developer Mode host is localhost and PC access uses a private token bridge. Read the ignored session record before maintenance. Ordinary direct SDB access is not the current route.

Commit only under the owner's configured AnthonMS identity, without co-author or generated-by trailers. Do not publish private operator history.
